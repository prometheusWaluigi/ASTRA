Field note i — what the station is for

The hunt brings home candidates — six clusters, 126 inscriptions, each tagged with an isomorphism note written at capture. The graph keeps them all. But a graph is a ledger, not a landscape. The field station takes one cluster at a time and builds the landscape the notes were already describing: the papers stop being entries and become specimens, pinned in a space built from the strongest find’s own grammar.
