Family-wide null — 50,000 replicates, correlations retained

Per target, the null hit-set is the union of formulas within that target's observed epsilon (baseline phi B=12). Replicates draw target vectors with log-uniform marginals on [0.05,0.5] and a Gaussian copula carrying the audit-A empirical correlation matrix (λ↔mH/v and mW/mZ↔on-shell sin²θ are ~±1; Cholesky jitter 1e-10). P(≥1 hit) = 1.000; expected hits = 4.49. The if-independent figure 1.000 is shown for contrast only — correlated per-target probabilities are never multiplied.
