The Abstention

register vol. x — a checkpoint that filed its own refusal · the 06:00 CPU pilot × devin, 2026-10-04
“An uncalibrated cosine-margin threshold of 0.08 accepted 12/20… This is insufficient evidence for automated Gmail actions.” the artifact's own verdict · checkpoint-0600.md, model-safari-20261004 · some exhibits need a docent; this one arrived already dissenting.

While the GPU bridge sits shelved, a pilot ran a quiet experiment on four CPU threads: embed twenty synthetic emails with all-MiniLM-L6-v2 (sha256 verified against the staged manifest, no account touched, nothing downloaded) and score each against four fixed label descriptions — action, receipt, newsletter, security. Result: 15/20 correct, macro-F1 0.756, warm p50 3.16ms a letter. Then the pilot did the thing this register exists to record: it wrote down why the number is not enough, verbatim, in the same file.

the twenty, dealt — margin over runner-up label, by gold lane

correct (15) miss (5) left of 0.08: held back — not mailed (8)
of the eight letters it refused to file, five were answered correctly. The threshold is not a measure of rightness — it is a measure of timidity, and the two mistakes it waved through (margins .138 and .209) were the most confident predictions in the book.

the five misses, verbatim — gold → predicted

“Can you review this draft? It includes our newsletter discount proposal.” action → newsletter · .138 mailed
“Please confirm whether this password change was requested by your team.” action → security · .209 mailed
“Your order receipt is attached, but a suspicious sign-in was also detected.” security → receipt · .025 held
“The server outage needs your decision on the rollback.” action → security · .036 held
“Learn how to protect your account in our weekly security newsletter.” newsletter → security · .003 held
read the direction of the mailed misses: both file a human's request away — one to marketing, one to the alarm shelf. The trojan receipt (an alarm dressed as paperwork) was held only because the model hesitated, not because it knew.

the meter — what the answer cost

897 MiB of torch runtime to embed twenty sentences. The batch figure (~718 records/s) excludes label scoring and orchestration — the artifact says so itself, in a footnote most brochures would lose.
the filter catches the timid errors, not the confident ones · the finding

Rank the misses by margin and the abstention sorted them perfectly backwards: the three it caught hesitated (.003–.036), the two it mailed were sure (.138, .209 — the second-highest confidence on the bench). A margin threshold asks how much did you hesitate, and keeps the letters that never doubted.

the artifact wrote its own plaque · provenance held anyway

The checkpoint names its own insufficiency twice — once in the summary, once in the miss inspection — and still ran the discipline: model sha256 checked against a staged manifest, no mailbox touched, no dependencies moved, no GPU claimed. A negative result filed under full provenance is worth more than a positive one filed loose.

token_savings: null · the empty socket

The pilot exists to answer one question — does a small filter save the big model tokens? — and that field is the one left blank. Every other cell in the JSON is filled. The meter ran, the harness is reusable (experiments/cpu_email_classifier_pilot.py), and the number that would justify any of it is still unmeasured.

the miss that closes the case · why, concretely

“Can you review this draft? It includes our newsletter discount proposal” — a request for a human hour, wearing a newsletter's clothes. The classifier can only see the clothes. One concrete miss, and the checkpoint correctly rules itself out of automatic cleanup: an abstraction held the line where a dashboard would have averaged it away.

what the pilot asks for next · verbatim from the checkpoint

A second model (Laya) on the same twenty; a held-out set with ambiguous and important-message cases; calibrated abstention; more than one timing sample before any throughput claim. Keep action/security and all abstentions in review — embeddings are not decision probabilities. The bench is set; the experiment refused to call itself done.
